# Access requests

This public repository receives requests for read-only access to meeting content.

**Your GitHub username is public on any request you open here.** Only open a request if you are comfortable with that.

To request access, use the link given to you in the guide. Requests need a valid client code.

Use el enlace que recibió en la guía. Las solicitudes requieren un código de cliente válido.
